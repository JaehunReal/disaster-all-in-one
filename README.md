# 재난 올인원 · 사고상황보고서

119 관제일지(엑셀)를 올리면 **화재·구조 등 사고상황보고서**를 자동 작성하고 한글(.hwpx)·Word(.docx)·PDF로 내보내는 웹 도구

## 1. 개요
- 서버 없이 브라우저에서만 동작(관제일지·입력 내용은 **이용자 PC의 브라우저 안에서만** 처리·저장)
- 외부 통신: 「주소로 지도 자동 가져오기」 사용 시에만 OpenStreetMap 서버로 주소 문구 전송
- 배포 형태
  - 단일 파일: `python build.py` → `dist/재난올인원.html` (더블클릭 실행, 행정망 PC용)
  - 웹: Vercel(`vercel.json`) → `python3 build.py dist/index.html` 로 빌드

## 2. 구성
| 폴더/파일 | 내용 |
|---|---|
| `index.html`, `css/`, `js/` | 화면·기능 소스 |
| `lib/` | SheetJS(엑셀 읽기, Apache-2.0), docx(Word 생성, MIT) |
| `template/` | 한글 서식(`서식.hwpx`), 서식 작성규칙, 기본 서식 생성 스크립트 |
| `tests/` | 개발용 시험(가상 관제일지, HWPX 검사, rhwp 렌더링, 이미지 용량) |
| `build.py` | 서식 변환·검사 + 단일 HTML 빌드 |
| `vercel.json` | 웹 배포 설정(검색 노출 차단, 보안 헤더) |

## 3. 사용 순서
- ① 상단 [관제일지 엑셀 올리기] → 사건정보·동원현황·조치사항 자동 기입
- ② 1~3단계 탭에서 확인·수정(인명피해 표, 재산피해, 사진 등)
- ③ 4단계 미리보기 → [한글로 저장] / [Word로 저장] / [인쇄·PDF]

## 4. 개발
```bash
python build.py            # 서식 검사 + dist/재난올인원.html 생성
python build.py --check    # 서식(template/서식.hwpx) 검사만
```
- 시험 방법은 `template/서식_작성규칙.md` 4항 참조

## 5. 유의사항
- 보고서 내용은 「대외유출주의」 자료 → 공용 PC 사용 후 [새 보고서]로 저장 내용 삭제
- 웹 배포 주소는 검색엔진 노출을 막아 두었으나, 주소를 아는 사람은 접속 가능
