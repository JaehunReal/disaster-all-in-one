# 한글(HWPX) 서식 작성 규칙

## 1. 개요
- 「한글로 저장(.hwpx)」은 이 폴더의 `서식.hwpx`에 보고서 내용을 채워 만듦
- 서식을 바꾸려면 한글에서 `서식.hwpx`를 고쳐 저장한 뒤 `python build.py` 실행
  - 빌드할 때 자리표시를 자동 검사하고, 오류가 있으면 빌드를 멈추고 알려 줌
- 현재 `서식.hwpx`는 기본 서식(`make_template.py`로 생성). 본부 실제 서식으로 교체 가능

## 2. 자리표시 종류

### 가. 한 번만 나오는 값 — `{{이름}}`
| 자리표시 | 내용 | 자리표시 | 내용 |
|---|---|---|---|
| `{{보안표시}}` | 대외유출주의 | `{{보고서제목}}` | 화 재 등 사 고 상 황 보 고 서 |
| `{{수신}}` `{{참조}}` `{{발신}}` | 머리말 | `{{발신지}}` | 119종합상황실 |
| `{{보고일자}}` `{{작성자}}` `{{보고책임자}}` | 머리말 | `{{관할}}` | ○○소방서(줄바꿈)(○○119안전센터) |
| `{{접수시간}}` | 14:03 | `{{제목}}` | 대구 북구 ○○동 화재 |
| `{{사고내용제목}}` | 바. 사고내용 (건물구조 유무에 따라 글자 바뀜) | `{{인명피해}}` | 경상 2명(구급대 이송 1, …) |
| `{{재산피해}}` | 1억 2,300만원(동산 …) | `{{인원}}` `{{장비}}` | 동원현황 |
| `{{보험}}` | 보험가입내역 | | |

- 앞뒤 글자는 서식에 그대로 둠 (예: `  가. 인명피해 : {{인명피해}}`)

### 나. 반복 문단 — `{{#이름}}`
- 자리표시가 든 문단 하나가 견본이며, 자료 수만큼 복제됨(글자모양·문단모양 그대로)
- 자료가 없으면 견본 문단은 지워짐
- **연달아 놓인 반복 문단은 한 묶음**으로 보고, 실제 순서대로 섞어서 나옴

| 묶음 | 자리표시 | 내용 |
|---|---|---|
| 발생개요 | `{{#개요}}` + `{{#개요비고}}` | 가. 일시 … / ※ 용도 : … (대상 다음에 비고) |
| 사고내용 | `{{#사고내용}}` | ○ 줄 |
| 재산피해 비고 | `{{#재산비고}}` | ※ 부동산 : … |
| 조치사항 | `{{#조치}}` + `{{#조치굵게}}` + `{{#조치없음}}` | 일반 줄 / 주요사건(굵게) / 없을 때 문구 |
| 그 밖의 사항 | `{{#기타}}` | ○ 줄 |

- 굵게 줄은 `{{#조치굵게}}` 견본 문단의 글자모양을 그대로 씀 → 서식에서 굵게(또는 색)로 지정

### 다. 반복 표 행 — `{{사상자.칸이름}}`
- 인명피해 표에서 자리표시가 든 행 하나를 견본으로 사상자 수만큼 복제
- 칸 이름: `연번` `성명` `나이성별` `부상정도` `이송병원` `구급대` `비고`
- 사상자가 없으면 표 전체가 빠짐

### 라. 첨부 그림 — `{{#첨부시작}}`, `{{그림.이름}}`
- `{{#첨부시작}}` 문단: 첨부 쪽 시작(문단모양에 「쪽 나눔 앞」 지정). 그림이 없으면 지워짐
- 그림 표: 1행에 칸 여러 개, 칸마다 **견본 그림 1개 + `{{그림.이름}}`**
  - 칸 수만큼 그림이 한 행에 들어가고, 행이 자동으로 늘어남
  - 그림은 견본 그림 크기 안에 비율을 지켜 들어감 → 견본 그림 크기 = 최대 크기
- 순서: 위치도·건물전경 → 현장사진 1, 2, 3, 4

## 3. 서식 수정 시 주의
- 자리표시는 **한 번에 입력**(중간에 글자모양을 바꾸지 않음)
  - 나뉘어 저장돼도 프로그램이 합쳐 처리하지만, 빌드 시 알림이 나옴
- 서식에 없는 자리표시 항목은 보고서에 나오지 않음(빌드 시 알림)
- 알 수 없는 자리표시는 빈칸으로 처리됨(빌드 시 알림)
- 반드시 「HWPX 문서(*.hwpx)」 형식으로 저장

## 4. 개발자 검증(배포본에는 포함되지 않음)
| 순서 | 명령 | 확인 내용 |
|---|---|---|
| ① | `python build.py` | 서식 변환·검사, 결과물 생성 |
| ② | `node tests/hwpx_e2e.mjs dist/재난올인원.html tests/fixtures/sample_log.xlsx out.hwpx` | 가상 관제일지로 한글 파일 저장 |
| ③ | `python tests/check_hwpx.py out.hwpx` | ZIP 순서, XML 문법, 남은 자리표시, 그림 등록 |
| ④ | `node tests/rhwp_render.mjs <rhwp폴더> out.hwpx out_png` | rhwp(@rhwp/core)로 열어 쪽 그림 확인 |
| ⑤ | `node tests/split_test.mjs dist/재난올인원.html` | 나뉜 자리표시 처리 |
- ②④⑤는 Playwright 필요(`PW_BASE` 환경변수로 위치 지정 가능), ④는 `npm pack @rhwp/core` 후 `rhwp.js`·`rhwp_bg.wasm`이 든 폴더 지정
- 최종 확인은 한글 2018 이상에서 직접 열어 봄
